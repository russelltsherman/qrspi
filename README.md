🎓 The 8 Phases (Summary)

Questions (Q) - 20 min - Force exploration of codebase
Research (R) - 45 min - Document current system (zero opinions)
Design (D) - 40 min - Propose architecture with human feedback
Structure (S) - 30 min - Break into vertical slices
Plan (P) - 40 min - File-by-file implementation roadmap
Work Tree (W) - 30 min - 30-minute tasks with dependencies
Implement (I) - Variable - Write code following plan
PR (P) - 15 min review - Code review (should be boring)

Total alignment: 2.5 hours
Total implementation: 2-6 hours (depends on complexity)
Total: 5-10 hours per feature (similar to unstructured, much better quality)
