**Ticket:** RUS-19
**Design:** design.md @ 2026-06-04T00:00:00Z
**Structure:** structure.md @ 2026-06-08T00:00:00Z

## Summary

Adds a new self-contained agent skill at `.claude/skills/atmos/` that teaches an
agent to drive the Cloud Posse `atmos` CLI across the full Terraform component
lifecycle. The skill follows the in-repo `qrspi-ticket`/`qrspi-work` self-contained
archetype (no `.claude/agents/` wrapper) and uses prose-pointer progressive
disclosure: a lifecycle-organized `SKILL.md` body under the 500-line/5000-token
budget, with depth offloaded to five `references/*.md` docs. This is the repo's
first multi-reference skill, so reviewers should focus on (1) frontmatter
conformance to the in-repo five-field schema with `name: atmos` matching the
directory, (2) that every body section ends in a reference pointer that resolves
with no orphans, and (3) the factual accuracy of the atmos CLI flags and YAML
schema in the references. The skill is intentionally NOT indexed in any catalog
(`.claude/CLAUDE.md`, `README.md`, etc.) per revised-design / reviewer direction —
it is discovered solely via its `SKILL.md` frontmatter.
