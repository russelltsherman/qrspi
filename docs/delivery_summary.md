## FAQ

**Q: Does QRSPI take longer than unstructured prompting?**
A: No. It takes similar time for medium features, and saves time for complex features. The key: include debugging time in your comparison.

**Q: What if I don't have time for alignment?**
A: Use QRSPI only for medium+ complexity. Skip for simple features.

**Q: Can I use this with other AI models?**
A: Yes. The prompts are Claude-specific, but the framework is model-agnostic. Adapt the prompts for your model.

**Q: What if my agent hallucinates anyway?**
A: Check which phase it happened in. If Phase 1-5 (alignment), you caught it before code. If Phase 7 (implementation), the plan wasn't detailed enough. Debug and iterate.

**Q: How do I train multiple agents on QRSPI?**
A: Use the system prompt approach from Practical Application Part 3. Include QRSPI instructions in the system prompt, not in user messages.

**Q: Can I skip Work Tree (Phase 6)?**
A: Yes, if feature is straightforward. But keep it for large features (provides clarity).

**Q: What if Design phase feedback gets extensive?**
A: That's normal. Agent rewrites design (brain surgery). Better to catch now than in code review.
